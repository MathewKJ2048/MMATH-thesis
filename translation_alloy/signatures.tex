Signatures are represented by sets of string atoms, with each top-level signature being assigned a specific string prefix. For the given model, sigs A and C are top-level sigs, while B is a descendant of A in the sig hierarchy.

\begin{lstlisting}
sig A {}
sig B extends A {}
sig C
\end{lstlisting}

This is translated as:

\begin{lstlisting}
A \in SUBSET {"A0","A1",A2"}
/\ B \in A
/\ C \in {"C0","C1",C2"}
\end{lstlisting}
